# Tank Battle Game

Một game **Tank Battle** được phát triển bằng **C++** và **SFML** trong khuôn khổ môn học Lập Trình Hướng Đối Tượng.  
Người chơi sẽ điều khiển xe tăng để chiến đấu với kẻ địch hoặc với người chơi khác trong chế độ PvP.

---

##  Tính năng
-  Người chơi (PlayerTank) điều khiển bằng phím WASD + Space để bắn.
-  Thêm Player 2 (PvP mode) điều khiển bằng phím mũi tên + Enter để bắn.
-  Các loại enemy tank thông minh, di chuyển và bắn đạn về phía người chơi.
-  Thanh máu (HP bar) và hệ thống điểm (Score).
-  Menu chọn chế độ chơi (vs Enemy, PvP).
-  Đồ họa 2D bằng thư viện **SFML**.

---

##  Điều khiển

## Player 1
- Di chuyển: `W A S D`
- Bắn: `Space`

## Player 2
- Di chuyển: `Arrow Keys`
- Bắn: `Enter`

---


##  Cài đặt & chạy game

# Yêu cầu

- [SFML 2.6.1](https://www.sfml-dev.org/download.php)
- CMake hoặc Visual Studio / VS Code (cấu hình sẵn SFML)

# Cách chạy

1. Clone project về máy:  
   - Bấm nút **Code → Download ZIP** trên GitHub  
   - Hoặc dùng Git: `git clone https://github.com/DuyPhan061102/Tank_Battle.git`

2. Mở project bằng **Visual Studio** hoặc **VS Code**.

3. Build và Run để chơi game.
